# Pedal Steel Guitar

## Overview

I decided to make this project because I love the sound of pedal steel guitar, but I couldn't afford one. So, I made one that doesn't use the super expensive hardware that makes them so costly, but instead uses a digital algorithm to change the pitch instead. How cool is that?

## How It Works

This works by taking the input from the strings and changing the pitch in software, as opposed to a regular pedal steel, which changes the pitch by actually changing the string tension.

By using a digital algorithm instead of the expensive mechanical hardware, this project aims to recreate the pitch-bending effect of a pedal steel guitar in a different way.

## Challenges and What I Learned

This project proved challenging, as it required me to work with a lot of things that I had never used before in EasyEDA, but I learned a lot about routing in the process.

The code was also extremely challenging because I don't work with audio in code very often either, but I learned a lot doing it too.

Overall, this project helped me learn more about PCB design, routing, and audio processing in software.
