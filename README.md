# Pedal Steel Guitar
I decided to make this project because I love the sound of pedal steel guitar but I couldn't afford one, so I made one that doesn't use the super expensive hardware that makes them so costly, but instead uses a digital algorithm to change the pitch instead, how cool is that? This project proved challenging as it required me to work with a lot of things that I had never used before in easyeda,but I learned a lot about routing in the process. The code was also extremely challenging because I don't work with audio in code very often either, but I learned a lot doing it too.
